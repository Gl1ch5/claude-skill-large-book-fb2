## 0. Прочитай (Read целиком)
1. `.claude/skills/large-book-fb2/SKILL.md` — навык. Этапы 1–2 (вопросы, «Подходит?») УЖЕ ПРОЙДЕНЫ с пользователем: решения — в `BRIEF.md` или `bible.md` книги. НЕ задавай вопросов, НЕ используй AskUserQuestion, НЕ жди подтверждений. Выполняй этапы 3–5.
2. `.claude/skills/large-book-fb2/references/craft.md` и `references/styles.md`.
3. `books/<SLUG>/BRIEF.md` (если есть) и `books/<SLUG>/bible.md`.

## 1. Библия и план (этап 3)
- Каркас (`plan/parts/part_NN.json`) уже создан командой skeleton — не пересоздавай его.
- Если `bible.md` — пустой шаблон, заполни ВСЕ разделы по BRIEF.md (паспорт стиля, ядро, мир, персонажи с манерой речи, структура, финал, линии, тайны, ружья, хронология, глоссарий). Если библия уже заполнена — используй её как есть (она главная).
- Заполни `book.json`: `spoilers_ok`: false, `pov`, `rating`: "18+", `ending` (кратко), `annotation` (2–4 предложения без спойлеров), `keywords`. Автор — всегда «Павел М».
- Составь план: удобнее всего написать `books/<SLUG>/plan/plan.md` в формате из docstring `.claude/skills/large-book-fb2/scripts/plan_from_md.py` (части `# Часть N | Название`, главы `## N | Название | точка зрения`, абзац содержания, сцены строками `- …`, крючок `=> …`) и выполнить `python3 $S/plan_from_md.py books/<SLUG>`. Затем `python3 $S/book_plan.py check books/<SLUG>` — 0 незаполненных мест.

## 2. Написание (этап 4) — ВСЕ главы по порядку
Для каждой главы N:
1. `python3 $S/book_plan.py next books/<SLUG> --chapter N`.
2. Пиши главу ДВУМЯ записями Write: `chapters/cNNNN.txt` (первая строка `# Название главы`, первая половина ~55% объёма) и `chapters/cNNNN.2.txt` (продолжение до конца главы, без заголовка). NNNN — с ведущими нулями. Объём главы — НЕ МЕНЬШЕ цели из `next` (пиши с запасом +10%). Каждая сцена плана — развёрнутая сцена на 6–12 тысяч знаков: диалоги, действие, детали, а не пересказ.
3. `python3 $S/book_status.py books/<SLUG> --from N --to N` — если короче цели, допиши полноценную сцену через Edit в `cNNNN.2.txt`.
4. `python3 $S/book_lint.py books/<SLUG> --from N --to N` — исправь штампы и повторы через Edit.
5. Конспект `plan/summaries/cNNNN.md` (8–12 строк: события, где герои, что узнали, ружья, новые имена). Это твоя память — не перечитывай написанные главы целиком, опирайся на конспекты и библию.
Не останавливайся между главами. Разметка: абзац = строка; `* * *` — смена сцены; диалог через «— »; `*курсив*`; эпиграф `> …` в начале главы.

## 3. Сборка (этап 5)
```
python3 $S/book_status.py books/<SLUG> --short
python3 $S/book_lint.py books/<SLUG>
python3 $S/book_build.py books/<SLUG> --zip
python3 $S/book_validate.py books/<SLUG>/out/<SLUG>.fb2
```
Короткие главы допиши. Ложные срабатывания lint — в `book.json` → `lint_ignore`.

## Правила
- Законы craft.md: вход в сцену поздно, выход рано; цель — препятствие — поворот; конкретные детали всех чувств; подтекст; разные голоса; меняющийся ритм; ни одного штампа из чёрного списка; без морали и итогов; концовка главы — крючок.
- Голос — по паспорту стиля и пробному абзацу.
- Рейтинг 18+, финал горький (как в BRIEF/bible).
- Не запускай git. Не трогай другие книги. Если в папке уже есть написанные главы (их пишут другие) — не переписывай их, начинай с первой ненаписанной из твоего диапазона.
- Если контекст заканчивается — это нормально: всё состояние в файлах (book_status.py + book_plan.py next). Продолжай до конца книги.

В конце ответь 2–3 строками: путь к FB2, страниц/знаков, частей/глав, результат проверки FB2 (или на какой главе остановился).
