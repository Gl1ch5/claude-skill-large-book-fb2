# Knigiskil — правила для агента

## Псевдоним автора

**Во всех книгах автор — «Павел М».** Это постоянный псевдоним для каждой книги без исключений:
в `book.json` (`author`), в FB2 (`<author>`), на титуле и в аннотации. Не спрашивай об авторе и не меняй его.

## Книги

- Книги пишутся навыком `large-book-fb2` (`.claude/skills/large-book-fb2/SKILL.md`), каждая — в своей папке `books/<slug>/`.
- Скрипты навыка: `.claude/skills/large-book-fb2/scripts/` (Python 3, без зависимостей).
- Итоговый файл книги: `books/<slug>/out/<slug>.fb2` (+ `.fb2.zip`).
